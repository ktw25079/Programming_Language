## 구현 선택과 확인 범위

- 1주차: `mybook` 솔루션에 `ch01`·`ch02`·`ch03`과 소스·헤더·리소스 필터를 구성했다. XML과 참조 경로, 네 구성의 MSBuild 빌드·실행을 검사했다. Visual Studio GUI에서도 Debug/x64 빌드와 ch01 실행(종료 코드 0)을 확인했다.
- 7주차: 분기 문제는 교재의 if 설명보다 실습자료에서 지정한 switch 조건을 따랐다. 세율은 교재 표 그대로이며 현재 세법을 구현한 계산기가 아니다.
- 8주차: PDF p.10의 중복된 과제 2는 파일명 `assignment04`로 구분했다.
- 9주차: 5×4 성적표의 점수는 그대로 사용하고, 학생 표시는 표의 행 순서인 student1~5로 표현했다.
- 10주차: `void copyarray(int from[], int to[], int n)`과 교재의 두 배열을 반영했다.
- 11주차: 중간점검 세 문항을 점화식 S(0)=0, S(n)=n+S(n−1), `nplus`, 1~10 출력으로 함께 구현했다.
- 12주차: main 파일의 전역 guess·지역 input, 별도 파일의 testNum, 용량 3·top=-1 스택을 반영했다. 게임의 정답은 switch의 break 대신 return으로 종료한다. p.459의 스택 후속 출력 예시는 제공되지 않았으므로 그 화면과의 일치는 확인하지 않았다. 실습에서 요청한 push/pop·LIFO 동작은 구현·검증했다.
- 13주차: double 포인터로 최솟값을 탐색한다. 교재에 전체 배열 초기값이 없어 예시의 첨자 2·최솟값 1.5를 만족하는 배열을 구성했다. int/short 예제는 직접 형변환 역참조의 별칭 위반을 피하도록 memcpy를 사용했고, 교재의 두 출력과 최종 정수값을 확인했다.

입력 프롬프트와 출력 라벨은 간결하게 작성하고, 문제에서 요구한 수치·배열·함수 원형·필드 폭을 코드와 검사에 반영했다.
