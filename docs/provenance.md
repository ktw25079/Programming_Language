# 출처와 작성 범위

## 참고 자료

사용자가 제공한 `프로그래밍언어.zip`의 이론 PDF 15개와 `프로그래밍언어 실습.zip`의 실습 PDF 13개를 참고했다. 강의 소개에는 교재가 **Perfect C 3판, 강환수·강환일·이동규, 인피니티북스, 2021**로 명시되어 있다. 문제 위치는 실습 PDF의 페이지를 기준으로 각 주차 README에 기록했다.

강의 PDF와 원본 ZIP은 로컬 참고자료로 보존하고 저장소에는 문제 요약과 새 구현을 넣었다. [원본 파일명과 SHA-256](source_manifest.json)은 참고한 자료를 식별하기 위한 기록이다.

## 새로 작성한 부분

C 풀이, Python 검증 도구, 기대 출력, 주차별 설명은 2026년 자료 정리 과정에서 Codex의 도움으로 작성했다. 제공된 ZIP에는 과거 제출 C 소스나 당시 실행 결과가 없어 원본 제출 코드라고 표시하지 않는다. `results/`와 각 주차의 로그는 이번 구현을 실제로 실행한 결과이다.

문제에 없는 배열값·용량·입력 범위는 주차별 README에 추가 선택 사항으로 명시했다. 교재 본문이 없는 문제는 별도 목록에 남겼다. 표준 C에서 정의되지 않는 signed overflow와 0 분모는 그대로 재현하지 않고 검사하거나 명시적으로 처리했다.
