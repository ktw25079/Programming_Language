# 출처와 작성 범위

## 참고 자료

프로그래밍언어 수업의 실습자료와 **Perfect C 3판(강환수·강환일·이동규, 인피니티북스, 2021)**을 참고했다. 주차별 README에 실습자료 페이지와 교재 페이지를 구분해 적었다.

저장소에는 문제를 짧게 요약한 설명과 풀이 코드를 담았다. 강의 PDF와 교재 사진은 포함하지 않았다.

## 구현과 실행 기록

C 풀이와 주차별 설명에 요구사항과 해결 방법을 정리했다. Python 검증 도구로 실제 출력과 기대 출력을 비교했으며, `results/`와 각 주차의 로그에서 실행 결과를 확인할 수 있다.

문제에서 정하지 않은 배열값과 입력 범위는 주차별 README에 적었다. 교재 문제 번호와 풀이에서 정한 조건은 [과제 안내](coverage.md)에서 확인할 수 있다. 정수 범위를 넘는 계산과 0으로 나누는 입력은 계산 전에 검사했다.
