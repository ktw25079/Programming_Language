# 출처와 작성 범위

## 참고 자료

사용자가 제공한 `프로그래밍언어.zip`의 이론 PDF 15개와 `프로그래밍언어 실습.zip`의 실습 PDF 13개를 참고했다. 강의 소개에는 교재가 **Perfect C 3판, 강환수·강환일·이동규, 인피니티북스, 2021**로 명시되어 있다. 추가로 제공된 교재 사진 21장을 확인했다. 각 주차 README에서 실습 PDF 페이지와 교재의 인쇄 페이지를 구분해 기록했다.

강의 PDF·교재 사진과 원본 ZIP은 로컬 참고자료로 보존하고 저장소에는 문제 요약과 새 구현을 넣었다. [원본 파일명과 SHA-256](source_manifest.json)은 참고한 자료를 식별하기 위한 기록이다.

## 구현과 실행 기록

C 풀이와 주차별 설명에 요구사항과 해결 방법을 정리했다. Python 검증 도구로 실제 출력과 기대 출력을 비교했으며, `results/`와 각 주차의 로그에서 실행 결과를 확인할 수 있다.

문제에 없는 배열값·용량·입력 범위는 주차별 README에 추가 선택 사항으로 명시했다. 교재 조건과 구현 선택, 제공되지 않은 후속 출력 예시는 [문항 대응](coverage.md)에 기록했다. 표준 C에서 정의되지 않는 signed overflow와 0 분모는 그대로 재현하지 않고 검사하거나 명시적으로 처리했다.
